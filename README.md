# Kuromii

Набор статических файлов и простая фронтенд-страница на Vite.

## О проекте

Это личный/демонстрационный сайт, содержащий HTML/CSS/JS ресурсы и сборку через Vite. Проект включает стили на Sass, компоненты JS и папку `public` для статических ассетов.

## Быстрый старт

Требования:
- Node.js (рекомендуется версия 16+)

Установка зависимостей:

```bash
npm i
```

Запуск в режиме разработки:

```bash
npm run dev
```

Сборка для продакшена:

```bash
npm run build
```

Локальный предпросмотр собранной версии:

```bash
npm run preview
```

## Структура проекта (кратко)

- `index.html` — входная HTML страница.
- `src/` — исходники проекта:
  - `js/` — JS-компоненты и логика.
  - `styles/` — SCSS файлы и структура стилей.
  - `assets/` — шрифты, изображения и аудио.
- `public/` — статичные файлы, которые копируются в сборку.
- `package.json` — скрипты и зависимости.

## Полезные скрипты

- `npm run dev` — запуск dev-сервера (Vite).
- `npm run build` — собрать проект для продакшена.
- `npm run preview` — запустить локальный сервер для просмотра собранной версии.

## Как внести изменения

1. Внесите изменения в файлы в `src/`.
2. Для стилей используйте SCSS в `src/styles/`.
3. Перезапустите `npm run dev` при необходимости (Vite автоматически перезагружает при изменениях).

## Вклад и дальнейшие шаги

- Добавить инструкции по деплою (Netlify/Vercel/GitHub Pages) при необходимости.
- Добавить тесты и CI по желанию.
